# 研究站点实现规格

确认日期：2026-10-22。

## 产品范围

- 首页 `/` 提供“每日 arXiv”和“企业 Agent Benchmark”两个入口，沿用已选定的黑金档案视觉风格。
- `/arxiv-daily` 显示日期选择、搜索和论文条目，默认日期为北京时间今天，可浏览此前成功归档的日期。没有当日数据时显示空列表，不回退到别的日期、不加额外提示。
- 日报显示英文标题及可用的中文标题、作者、分类、一句话总结和中英文摘要，提供 arXiv、HTML 和 PDF 原文链接。翻译失败使用英文，无额外失败徽标或提醒。
- `/enterprise-agent-benchmark` 迁入已有 101 项研究、九个业务标签、搜索及筛选，保留当前黑金排版、月份时间轴、互斥展开与底部 PDF 操作。74 项公共文件和 27 项 source-only 的公开边界、研究 ID、OSS 链接均保持原样。
- 原站移除两个研究路径和入口，不继续维护第二份研究页面。

## 每日采集

- 每天北京时间 13:30 由 GitHub Actions 运行一次，并支持手动指定日期补跑。
- 首次运行起积累新日报，不导入本地旧日报、不做历史回填。
- 沿用已启用的 arXiv CS 分类配置，只用原文标题和摘要，以 `\bllm|\bagent` 忽略大小写匹配，遇到 `robot` 保持旧排除规则。
- 以 arXiv 官方每日公告清单取得数据，保留真实来源批次与抓取时间；查询 API 提交日期不等同于公告日期，不能再用简单日期换算猜公告清单。
- 当天抓到的专题结果当天展示，不增加修订版排除或跨日期去重；同一条来源在同一次采集中可消除重复。
- 对选中论文生成中文标题、中文摘要及一句话总结，同日重跑复用已成功译文；翻译失败回退英文，保留可重试状态，不将回退误记为成功。
- 正常有效空结果归档为零篇，不维护节假日日历。HTTP 失败、限流或解析错误必须报错，不能发布成零篇；不得发布被截断的抓取结果。
- 只归档 JSON，不保存每日论文 PDF，不做译文人工校对。

## 发布与部署

- JSON 按日报日期提交到仓库长期备份，并上传 OSS 独立的 `research/arxiv-daily/` 前缀。Artifact 仅用于短期排错。
- OSS 先上传并验证不可变的每日对象，最后更新索引。索引使用短缓存，带内容哈希的每日对象可长缓存。
- 前端从 OSS 读取 JSON，新增来源 `https://research.cyunlab.com` 的 GET/HEAD CORS，保留已有来源。
- ECS 使用独立研究站发布目录、DNS、HTTPS 和 Nginx 配置。静态页面代码变化时构建并原子切换发布目录，保留上一版以便回退。
- 新站验证成功后再撤除旧站研究路由。官网云景首页和既有产品规则继续正常工作。
- 公共仓库只含公开源码、元数据、配置模板和依赖锁，不复制私有仓库历史、真实环境文件、本地论文库、运行回执或日志。代码 MIT，论文与字体保留各自许可。

## 测试边界

测试限定于已确认规格中的公开边界：采集命令到每日 JSON；页面到 JSON；发布结果到公网 HTTP。外部网络与时间可用固定响应替代，不校对译文内容、不绑定内部组件结构；每个切片先观察失败，再实现使其通过的行为。
